# Content Flow

Официальная страница выпусков **Content Flow** для Windows.

## Скачать

Последняя стабильная версия находится на странице [Releases](https://github.com/rew8tuyghnwe4outihj/content-flow-releases/releases/latest). Скачивайте файл `ContentFlow-Setup-<версия>.exe`.

## Проверить файл

Каждый релиз содержит `SHA256SUMS.txt`. Для версии 1.0.2:

```powershell
Get-FileHash .\ContentFlow-Setup-1.0.2.exe -Algorithm SHA256
```

Ожидаемый SHA-256:

```text
7FA729EA07B69B729D3BD9A7B034863EA53E4E97A596AC6284B2A0A0AABA13F8
```

## Обновления

Content Flow проверяет опубликованный `Latest` release в фоне при каждом запуске. Приложение показывает изменения и открывает ссылку на установщик только после подтверждения пользователя. GitHub-токены в программу не вшиваются.

## Важно

Начиная с версии 1.0.2 установщик включает совместимый Chromium, поэтому файл стал больше, зато Content Flow не зависит от системного Chrome или Edge.

Установщик пока не подписан доверенным сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Не отключайте SmartScreen глобально и скачивайте программу только с этой страницы.

В этом репозитории нет исходного пользовательского каталога, фотографий, сессии WhatsApp, настроек или других личных данных.
