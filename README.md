# Content Flow

Официальная страница Windows-версии **Content Flow**.

## Скачать

Последняя стабильная версия находится на странице [Latest Release](https://github.com/rew8tuyghnwe4outihj/content-flow-releases/releases/latest). Скачивайте файл `ContentFlow-Setup-<версия>.exe`.

## Проверить файл

Каждый релиз содержит `SHA256SUMS.txt`. Для версии 1.0.11:

```powershell
Get-FileHash .\ContentFlow-Setup-1.0.11.exe -Algorithm SHA256
```

Ожидаемый SHA-256:

```text
BEBB629AD6D51816AF2A65056C0176FE81B259CD66F483A6E8C600AF4DAA75F8
```

## Что изменилось в 1.0.11

- Исправлена ложная остановка рассылки после успешной отправки фотографии в групповой чат.
- Одна серая серверная галочка теперь корректно подтверждает групповую отправку.
- Быстрый переход от часов загрузки к галочке больше не теряется между обновлениями WhatsApp Web.
- Подтверждение принимается только для единственной новой карточки с точными фотографией и подписью; входящие, старые, текстовые и неоднозначные сообщения не считаются успехом.
- Защита от дублей сохранена: при действительно неопределённом результате автоматического повтора нет.
- Диагностика тайм-аутов стала точнее и не сохраняет личные данные переписки.

## Обновления и браузер

Content Flow проверяет обновления в фоне при каждом запуске и показывает список изменений до установки. GitHub-токены в программу не вшиваются.

Установщик не содержит отдельную копию Chromium и весит около 78,5 МБ. Content Flow использует установленный Google Chrome или Microsoft Edge, но хранит WhatsApp-авторизацию в собственном локальном профиле.

Если WhatsApp вышел из аккаунта, откройте кнопку **WhatsApp Web** в Content Flow и заново отсканируйте QR-код.

## Важно

Установщик пока не подписан доверенным сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Не отключайте SmartScreen глобально и скачивайте программу только с этой страницы.

В репозитории нет исходного пользовательского каталога, фотографий, сессии WhatsApp, настроек или других личных данных.
