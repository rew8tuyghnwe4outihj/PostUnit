# Content Flow

Официальная страница Windows-версии **Content Flow**.

## Скачать

Последняя стабильная версия находится на странице [Latest Release](https://github.com/rew8tuyghnwe4outihj/content-flow-releases/releases/latest). Скачивайте файл `ContentFlow-Setup-<версия>.exe`.

## Проверить файл

Каждый релиз содержит `SHA256SUMS.txt`. Для версии 1.0.13:

```powershell
Get-FileHash .\ContentFlow-Setup-1.0.13.exe -Algorithm SHA256
```

Ожидаемый SHA-256:

```text
B48C4F347B5E6BDF14E9E606BC40F0F452629495AE7CF85783FFD133AB963F28
```

## Что изменилось в 1.0.13

- Удалена ложная DOM-проверка текста подписи, из-за которой WhatsApp Web закрывал редактор и перезагружался после корректного ввода многострочного текста.
- Отправка в чат подтверждается устойчивым закрытием media editor, без зависимости от разметки исходящего сообщения и вида галочек.
- Сохранены строгая привязка к получателю, обычной фотографии, полю подписи и единственной кнопке Media Send.
- Окно `Discard selection?` обрабатывается только как продолжение закрытия конкретного редактора; посторонние диалоги не затрагиваются.
- После восстановительной перезагрузки повтор той же попытки запрещён, поэтому браузер больше не может войти в reload-цикл.
- Ветка публикации статусов не менялась.

## Обновления и браузер

Content Flow проверяет обновления в фоне при каждом запуске и показывает список изменений до установки. GitHub-токены в программу не вшиваются.

Установщик не содержит отдельную копию Chromium и использует установленный Google Chrome или Microsoft Edge. Сессия WhatsApp хранится только локально на компьютере пользователя.

## Важно

Установщик пока не подписан доверенным сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Не отключайте SmartScreen глобально и скачивайте программу только с этой страницы.

В репозитории нет пользовательского каталога, фотографий, сессии WhatsApp, настроек или других личных данных.
