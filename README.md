# PostUnit

Официальная страница Windows-версии **PostUnit**.

**PostUnit** — приложение для автоматической и удобной рассылки постов в чаты и статус WhatsApp.

## Скачать

Последняя стабильная версия всегда доступна в разделе [Releases](https://github.com/rew8tuyghnwe4outihj/PostUnit/releases/latest).

Скачивайте установщик с именем:

```text
PostUnit-Setup-<версия>.exe
```

Например:

```text
PostUnit-Setup-1.0.0.exe
```

## Установка

1. Откройте последний релиз.
2. Скачайте `PostUnit-Setup-<версия>.exe`.
3. Запустите установщик.
4. Установите PostUnit.
5. Запустите приложение и активируйте лицензию в разделе **«Лицензия»**.

## Лицензия

Лицензионный ключ приобретается через официальный Telegram-бот PostUnit.

После подтверждения оплаты ключ выдаётся пользователю в Telegram. Срок действия лицензии начинается при первой активации.

Один лицензионный ключ предназначен для одного компьютера. При смене компьютера можно обратиться в поддержку для сброса привязки устройства.

## Обновления

PostUnit автоматически проверяет наличие новой версии через GitHub Releases.

Для корректной работы автоматического обновления каждый релиз должен содержать установщик с именем:

```text
PostUnit-Setup-X.X.X.exe
```

Рекомендуемый формат тега релиза:

```text
vX.X.X
```

Например:

```text
v1.0.0
PostUnit-Setup-1.0.0.exe
```

## Браузер и данные

PostUnit использует установленный Google Chrome или Microsoft Edge для работы с WhatsApp Web.

Сессия WhatsApp и пользовательские данные приложения хранятся локально на компьютере пользователя. В этом репозитории не публикуются пользовательские сессии, фотографии, настройки или другие личные данные.
