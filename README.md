# Content Flow

Официальная страница Windows-версии **Content Flow**.

## Скачать

Последняя стабильная версия находится на странице [Latest Release](https://github.com/rew8tuyghnwe4outihj/content-flow-releases/releases/latest). Скачивайте файл `ContentFlow-Setup-<версия>.exe`.

## Проверить файл

Каждый релиз содержит `SHA256SUMS.txt`. Для версии 1.0.7:

```powershell
Get-FileHash .\ContentFlow-Setup-1.0.7.exe -Algorithm SHA256
```

Ожидаемый SHA-256:

```text
B5AAED3645316B6EA501E6FD0410C4291CF0468743D60194F754B137931135EB
```

## Обновления

Content Flow проверяет обновления в фоне при каждом запуске. Приложение показывает список изменений и открывает официальный установщик только после подтверждения пользователя. GitHub-токены в программу не вшиваются.

Версия 1.0.7 исправляет обработку завершённой WhatsApp-сессии и защищает браузерный профиль, возвращает компактные карточки, устраняет зависания и искажение пропорций в фоторедакторе, ускоряет большие категории и закрывает ошибки сохранения/переноса публикаций.

Если WhatsApp вышел из аккаунта, откройте кнопку **WhatsApp Web** в Content Flow и заново отсканируйте QR-код. Без активной локальной сессии поиск чата и отправка физически невозможны.

Начиная с версии 1.0.3, установщик не содержит отдельную копию Chromium и весит около 78,5 МБ. Content Flow автоматически использует установленный Google Chrome или Microsoft Edge, но хранит WhatsApp-авторизацию в собственном отдельном профиле.

## Важно

Установщик пока не подписан доверенным сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Не отключайте SmartScreen глобально и скачивайте программу только с этой страницы.

В репозитории нет исходного пользовательского каталога, фотографий, сессии WhatsApp, настроек или других личных данных.
